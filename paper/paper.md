# Introduction

Structural design software has always needed evidence that it computes what its documentation claims, and the profession has built that evidence from benchmark problems with known answers. Verification manuals of commercial programs, the NAFEMS benchmarks and the worked examples that code bodies publish alongside their standards give an engineer a way to check a program before trusting it with a real building. The arrival of language-model agents that drive engineering programs through tool interfaces such as the Model Context Protocol [@mcp2024] raises the stakes of that check. An agent can assemble a model, run an analysis and size every member in seconds, but it accepts the numbers the tools return, so an error in a tool propagates through the whole design without the pause in which an engineer would have noticed that a result looked wrong.

Pondus is a native program in which an agent and an engineer work on one structural model. The agent calls the same commands as the engineer's user interface, the analysis runs on the Stabileo engine [@stabileo], and the design follows ACI 318-19 [@aci318], AISC 360-16 [@aisc360] and EN 1993-1-1 [@en1993] among other codes. Stabileo ships its own verification suite against textbooks and design examples, so the engine's kernels were not the main concern. The concern was the layer that Pondus adds above the engine: the code that splits members, converts loads, carries slab loads to beams, assembles combinations, maps sign conventions and turns analysis results into the inputs of each design check. That layer is ordinary application code, written quickly, and it is exactly the code an agent depends on without seeing.

This paper reports a calibration of that layer against published reference values. The word calibration is used here in its everyday engineering sense of checking an instrument against known standards, and it corresponds to code and solution verification in the vocabulary of ASME V&V 10 [@asme2006vv10] and @oberkampf2010. No parameter was fitted to the references, so agreement means that the program reproduces the reference and disagreement means a defect, a deliberate simplification or a difference between editions of a code. The paper describes the method in Section 3, reports the results by aspect in Sections 4 to 7, analyses the defects the calibration found in Section 8 and states what was not calibrated in Section 9.

# The program and what needed calibration

Pondus is organised in four layers. The engine is Stabileo's `dedaliano-engine` at commit 7985e8c, vendored into the workspace with three marked source changes: a sign correction in the vertical Winkler foundation matrix, a sparse Cholesky test placed before the dense rank test that the plastic solver runs at every hinge event, which changes speed only, and a moving-load envelope kept at each end of an element (defect 14). The core library holds the model, the analysis wrapper, the design codes, the advanced analyses, the calculation report and the interchange formats. The MCP server exposes the core's commands to agents, and the desktop application exposes the same commands to the engineer through a ribbon, tables and a chat.

The analysis wrapper does more than pass the model to the engine. It splits every member at the nodes that lie on it, at every load break point and into at least eight elements, so each element carries a load that is linear along its length. It transfers slab loads to the edge beams along the 45° lines of each panel, or one way when the aspect ratio exceeds 2, or it meshes the slabs into MITC4 shell elements [@dvorkin1984] joined to the frame. It builds the seismic mass from the model's own load cases, scales the response spectrum result to the equivalent lateral force base shear, generates each shear wall as a wide column with rigid arms at every level, routes nonlinear members and supports to the engine's contact, cable and Winkler solvers, and computes pushover, moving-load envelopes, influence lines and construction stages on models of its own. The design code is Pondus's own for ACI 318 beams, slabs, columns and footings, for AISC 360 members and for the slab coefficient methods, and it wraps the engine's checkers for EN 1993-1-1, the EN 1992-1-1 cross-check, the shear tab bolt and weld groups, timber and masonry.

Each of these steps can be wrong while the engine underneath is right, because each step decides what the engine or the checker is asked. A wrong effective length, a wrong axis order or a missing coefficient produces a confident and plausible number. The calibration was therefore designed so that every comparison enters through the same functions the program uses when it designs a building.

# Method

## Reference values

Each comparison is recorded with its source, the quantity, its unit, the reference value, the Pondus value, the relative error, the tolerance and the kind of reference. A reference of kind *published* is a number printed in the cited source, such as the $\phi_c P_n = 892$ kips of AISC Design Example E.1C [@aisc2023examples] or the coefficient $w_{max} = 0.00406\,qa^4/D$ of Timoshenko and Woinowsky-Krieger's Table 8 [@timoshenko1959]. A reference of kind *closed-form* evaluates, in the test, a formula of the cited source, such as $6EI\Delta/L^2$ for a support settlement [@ghali] or the CQC combination of @derkiureghian1981, and the formula is named in the record. A reference of kind *independent* is an exact solution by another method, used for biaxial column capacity and for the flexural–shear continuum of a wall coupled to frames, whose frequency equation the test solves itself. Of the 470 comparisons, 331 are published, 118 closed-form and 21 independent.

The published values come from four groups of sources. The first is the set of inputs and printed answers that Stabileo records, with page numbers, from the AISC Design Examples v16 [@aisc2023examples], the SCI/CTICM Steel Buildings in Europe examples [@sbe2010], SCI P364 [@p364], the JRC Eurocode 2 worked examples [@jrc2014] and the INTI-CIRSOC examples [@inti2005; @inti301]. The second is the classical textbook literature of structural analysis, dynamics, stability and plates [@timoshenko1959; @timoshenko1961; @timoshenko1970; @roark; @hibbeler; @kassimali; @ghali; @mcguire; @chopra; @clough; @neal; @horne; @hetenyi; @ernst1965; @irvine]. The third is the ANSYS Verification Manual as reproduced by PyMAPDL [@ansysvm]. The fourth is a set of ACI 318 worked examples published by StructurePoint after @wight and other textbooks [@structurepoint], a scan of the ACI 318-63 Method 2 coefficient table in lecture notes of the University of Basrah [@hussain; @aci31863], and a timber column example by Dlubal [@dlubal; @nds2018].

## The rule that everything passes through Pondus

No comparison calls the engine's checkers directly. A frame problem is built as a Pondus model and solved by the Pondus analysis, so the member splitting, the load conversion and the reading of results are part of what is tested. A steel member is checked by the Pondus function that the design loop calls, `steel::check` for AISC 360 and `codes::check_ec3` for EN 1993-1-1, with the section properties the example prints converted to SI units. Where Pondus computes a property itself, such as $C_b$ from the moment diagram or $U$ from the end connection, the computed property is compared with the printed one as a separate row, so that an error in a property cannot hide inside an agreeing resistance. Where a design function bundles several clauses, the clause-level functions were exposed without changing any design result, so that the shear terms, the cracked and effective inertia, the torsion terms and the column section points can each be compared with the value the example prints.

## Units and tolerances

US examples were converted exactly (1 in = 25.4 mm, 1 ksi = 6.894757 MPa, 1 kip = 4.448222 kN) and the results were converted back to the example's units before comparison. The default tolerance is 0.5 %, which is half a unit in the third significant figure that published examples print. A wider band was allowed only for three documented reasons. Some sources print fewer figures, such as a buckling reduction factor of 0.65. The plate rows are a mesh convergence study whose coarse meshes are expected to differ. The SI form of ACI 318, which Pondus implements, rounds several constants of the US form, so $0.17\sqrt{f'_c}$ MPa replaces $2\sqrt{f'_c}$ psi and gives a concrete shear strength 2.4 % higher, and each such row states the offset its constant implies.

## Recording and treatment of discrepancies

The comparisons are Rust integration tests (`core/tests/calib_analysis.rs`, `calib_steel.rs`, `calib_concrete.rs`, `calib_walls.rs` and `calib_bridge.rs`) that assert each row against its tolerance and, when an environment variable names a directory, append the row to a CSV file. The tables and the figure in this paper are generated from those files, so the paper cannot quote a number that the tests did not produce. When a comparison failed, the cause was traced before anything was changed. A defect in Pondus was fixed, the whole test suite was run again, and the values before and after were recorded. A deliberate simplification of Pondus was kept, documented and, where it is conservative, asserted as such. A failure caused by the test model itself, such as a plate too thick for Kirchhoff tables, was corrected in the test and recorded as such.

# Results overview

Table 1 summarises the 470 comparisons by aspect, and Figure 1 shows the distribution of the absolute errors. Taken together, 358 comparisons agree within 0.1 %, 430 within 0.5 % and 449 within 1 %. The median absolute error is below 0.001 % because many comparisons, such as the 107 slab coefficients, the statically determinate frames and the Wood–Armer moments, are reproduced exactly.

Twenty-one comparisons differ from their reference by more than 1 %, and they fall into four groups whose causes are understood. Nine are the coarse meshes of the plate convergence study, which converge to within 0.9 % on the finest mesh (Section 5.2). Two are the biaxial column capacities by Bresler's load contour, which lie 8.2 % and 8.4 % below the exact skewed-axis capacity, so the method Pondus uses is conservative by that margin (Section 7.3). Six are concrete quantities that depend on the rounded SI constants of ACI 318, such as the 2.4 % in $\phi V_c$ and the 6.4 % that this offset becomes in the required stirrup strength $V_s = V_u/\phi - V_c$, because the latter is a difference of two similar numbers. Four are the third frequencies of the walls, 1.03 % to 1.12 % low because Pondus's piers deform in shear, which the Euler–Bernoulli references leave out and which a Timoshenko solution reproduces (Section 5.4). None of the twenty-one is a defect of Pondus.

# Analysis

## Statics, supports and slab load transfer

The linear static cases reproduce their references to rounding. The ANSYS VM2 overhanging beam gives a bending stress of 11 404 psi and a mid-span deflection of 0.18246 in against the printed 11 400 psi and 0.182 in, which are themselves rounded values of $Mc/I$ and $Ml^2/8EI$. VM4 gives the bar stress and the apex deflection exactly. A propped cantilever, a fixed-ended beam, a two-span continuous beam, a Gerber beam with an internal hinge, a Pratt truss and a three-dimensional L-frame loaded out of plane agree exactly with Roark, Hibbeler, Ghali and Neville, Kassimali and McGuire, Gallagher and Ziemian [@roark; @hibbeler; @ghali; @kassimali; @mcguire]. A fixed-base portal under lateral load sways 0.012 % more than the slope-deflection formula because the formula ignores the axial strain of the columns. Springs, settlements, temperature changes and a rigid diaphragm reproduce their closed forms exactly. A two-way slab panel of 4 m × 6 m under 10 kPa sends 80 kN to each long beam and 40 kN to each short beam, as the 45° tributary lines require, and the beams' moments match $w_0(3L^2 - 4a^2)/24$ for the trapezoid and $w_0 l_x^2/12$ for the triangle.

## Plates

Table 2 reports the convergence of Pondus's plate slabs, meshed with MITC4 elements, towards the Kirchhoff solutions of @timoshenko1959 for square plates of side $a = 4$ m and thickness $a/100$ with $\nu = 0.3$. The edges are rigid beams that are free in torsion for the simply supported plate and rigid in torsion for the clamped plate. Moments converge faster than deflections, and on the finest mesh every quantity lies within 0.9 % of the table. A first attempt with $a/h = 20$ overshot the clamped deflection by 3.8 % because the Mindlin elements carry transverse shear deformation, which is physical and of order $(h/a)^2$, so the plates were made thin for the comparison. At the default slab mesh of 0.5 m, which on a 4 m panel is close to the $n = 9$ row, deflections run 3–5 % low while moments are within 1 %. Plate deflections used for serviceability should therefore be checked on a mesh of $a/16$ or finer.

## Modal, seismic and time-history analysis

A uniform cantilever of 32 elements gives its first three lateral frequencies within 0.001 % of the $\beta_n L$ values tabulated by @clough, and a two-storey shear frame gives both frequencies within 0.06 % and the first-mode effective mass ratio of 0.9472 within 0.04 % of the closed form in @chopra, the small residual being the axial flexibility of the columns. A flat spectrum on that frame gives a CQC base shear within 0.16 % of the hand combination. The equivalent lateral force procedure of ASCE 7-22 [@asce722] was checked on two frames, one in the velocity branch of the spectrum and one stiff enough that its period of 0.038 s lies below $T_0$, and the period, $C_s$ and the base shear are exact after the defect described in Section 8 was fixed. No freely available printed ELF example with complete input data was obtained, so these rows check the equations rather than a printed example. An undamped single-degree-of-freedom system under a step ground acceleration reaches the dynamic amplification of 2 within 0.015 % at a time step of $T_n/200$.

## Shear walls under earthquake and dynamic loading

Pondus models a shear wall by the wide-column analogy [@staffordsmith1991]: a pier on the wall's centre line carries the wall section $t \times l_w$ with a shear area of $5A/6$, and rigid arms join it to the wall's ends at every level, where beams and the floor diaphragm connect. Every wall case in this section was built with the same `add_walls` command an agent calls, so the wall generation, the seismic mass, the modal and CQC analysis and the time-history solver are tested together. Table 3 summarises the 34 comparisons, all of which pass after the fix of defect 13, and Appendix A.4 lists them.

A cantilever wall 0.3 m thick, 2 m long and 60 m high, divided into 20 storeys and carrying only its own weight, gives its first three frequencies 0.077 %, 0.44 % and 1.03 % below the $\beta_n L$ values of @clough and its effective modal masses within 0.72 % of the flexural cantilever [@chopra]. The frequencies are low because the table describes an Euler–Bernoulli beam whereas Pondus's pier also deforms in shear, and a Timoshenko solution of the same wall predicts reductions of 0.062 %, 0.43 % and 1.01 %, so the shear area accounts for the offset almost entirely. The same wall under an undamped step of ground acceleration of 0.1 g, integrated at $T_1/400$, reaches a peak top displacement of 1027.9 mm against 1026.0 mm by the superposition of six flexural modes, a dynamic amplification of 2.029 against 2.025, which exceeds 2 because the higher modes add to the first.

The interaction of a wall with moment frames, which governs the earthquake response of most wall buildings, was checked against the flexural–shear continuum of @heidebrecht1973 and @miranda2005. In that model a flexural cantilever of rigidity $EI$ is tied by rigid floors to a shear cantilever of rigidity $GA$, and the single parameter $\alpha H = H\sqrt{GA/EI}$ moves the structure from a pure wall at $\alpha H = 0$ to a pure frame as $\alpha H$ grows. The test solves the continuum's frequency equation itself, after checking the solver against both limits and against an independent beam finite-element solution that agreed to four digits. The Pondus model is the 60 m wall joined by rigid diaphragms at 40 levels to two frames whose columns, sized to give the required $GA$, are axially rigid, so the frames act in shear alone as the continuum assumes. Over $\alpha H$ from 0.5 to 8, the first frequency lies 0.18 % to 0.33 % below the continuum, the second and third 0.50 % to 1.12 % below, and the first-mode effective mass 0.05 % to 0.18 % above. The wall's shear deformation explains about half of the first-mode offset at $\alpha H = 8$ and most of it at low $\alpha H$. The rest, about 0.1 %, comes from the minimum density of 1 kg/m³ that Pondus gives weightless members, which adds about 0.2 % to the mass of these lightly loaded models. At $\alpha H = 8$ the first-frequency error falls from 0.61 % at 10 storeys to 0.35 % at 20 and 0.33 % at 40, converging on that floor.

Torsional coupling, the mechanism that makes a wall on one side of a plan dangerous in an earthquake, was checked on a one-storey system of the kind @chopra treats in closed form. A 10 m square floor carries its mass on three edges, so the mass centre lies at $x = 6.67$ m, and it rests on four corner columns pinned at the top and on a 4 m wall along the fourth edge. The three coupled modes agree with the $3 \times 3$ eigenproblem of the rigid floor within 0.031 %, the share of the mass in $y$ of the two coupled modes within 0.043 %, and the CQC base shear in $y$ under a flat spectrum of 0.4 g within 0.017 %. Reaching that agreement needed two corrections to the test model, both recorded in the notes: the floor beams were first hinged at both ends, which made a mechanism with the pinned column tops, and then they were too flexible axially and in plan for the 47 Hz torsional mode, because only the model's own nodes join the diaphragm while the mass lies along the beams between them. The static stiffness of the floor matched the reference to six digits throughout, so neither correction concerned Pondus.

The wall-frame cases exposed defect 13 (Section 8). The rigid arms had an absolute stiffness, $E = 2.5\times10^7$ MPa on a section with $A = I = J = 1$, regardless of the wall they belonged to. A slender wall coupled to soft frames then puts a stiffness contrast of order $10^9$ into the stiffness matrix on top of the cantilever's own poor conditioning, and the solution loses precision silently, with global equilibrium still satisfied and no warning raised. At $\alpha H = 0.5$ and 40 storeys the first frequency came out 11.5 % high and the static top deflection 21 % low, whereas the same model at 10 or 20 storeys, or without its diaphragms, was right. The arms now take their own wall's section and 1000 times its modulus, so they remain rigid against the wall without an absolute stiffness, and models saved earlier have their arms rebuilt when they are opened.

## A full-scale wall building on a shake table

The comparisons so far are calibration in the sense of Section 3, because their references are exact for the model Pondus solves. A user also needs to know how close that model comes to a real building, which is validation in the vocabulary of ASME V&V 10 [@asme2006vv10]. Pondus was therefore compared with the measured dynamic properties of the full-scale seven-storey reinforced concrete wall building slice tested on the UCSD–NEES shake table between October 2005 and January 2006 [@panagiotou2011; @panagiotou2010]. These comparisons are recorded separately (`core/tests/validation_ucsd.rs`) and are not counted in the 470 calibration rows. Their differences combine the program's error with the modeller's choices and with the physics that a linear model leaves out. The slice resists lateral load in the direction of shaking with a single rectangular web wall 3.658 m long and 19.20 m high in seven storeys of 2.743 m, 0.203 m thick in the first and seventh storeys and 0.152 m between. It carries 3.66 × 8.12 m slabs on pin-ended gravity columns, and a flange wall and a post-tensioned precast pier provide transverse and torsional stability [@kelly2007]. The measured concrete strength averaged 41.4 MPa against 27.6 MPa specified [@kelly2007].

The Pondus model is the web wall alone, built with `add_walls` in three segments, on a fixed base, with $E = 4700\sqrt{41.4} = 30.2$ GPa and the gross section. The seismic weight was taken as $W = V_b/C_s = 292/0.15 = 1947$ kN from the design base shear and coefficient that the designers report [@panagiotou2010]. The wall's own weight of 281 kN comes from its concrete, and the remaining 1666 kN was placed at the floors in proportion to the slab thickness. The flange wall, the post-tensioned pier, the frame action of the slabs with the gravity columns and the flexibility of the shake-table foundation were left out, as a designer would leave them out of a model of the lateral system. Figure 2a shows the model as Pondus draws it. Table 4 compares the results with the frequencies identified from the test by @moaveni2011 and @panagiotou2010 and with two published models: the designers' uncracked three-dimensional model and the nonlinear ANSR-II model of the blind-prediction study [@kelly2007].

With gross sections, Pondus gives a first period of 0.542 s, 6.2 % longer than the 0.51 s identified from the first low-amplitude white-noise test, 8.4 % longer than the designers' uncracked three-dimensional model and 2.7 % shorter than the blind-prediction model. The mode shapes have the expected cantilever form (Figure 2b), and the second mode agrees more closely, at 10.62 Hz against 10.53 Hz identified from ambient vibration (+0.9 %) and 0.0941 s against 0.094 s in the blind-prediction model. The first mode is the one the omitted elements stiffen, because the flange wall, the post-tensioned pier and the slab–column frames act through the overturning of the whole slice, which @kelly2007 and @panagiotou2011 found to be significant, so a bare-wall model is expected to be somewhat long in $T_1$ while its second mode, dominated by the wall's own curvature, stays close. The ambient-vibration frequency of 2.23 Hz measured before any testing is 17 % above Pondus, because at those micro-amplitudes the concrete was uncracked with full tension stiffening, which twenty-five white-noise tests then reduced to the state behind the 0.51 s [@panagiotou2010]. The mass is a second source of uncertainty, because the reported $C_s$ of 0.15 has two figures, which leaves $W$ uncertain by about ±3 % and $T_1$ by ±1.7 %.

The stiffness that an engineer assumes matters far more than these differences, as Figure 2c shows against the periods identified through the test sequence. With $E$ from the specified rather than the measured strength the first period lengthens to 0.600 s (+17.6 %). The effective stiffnesses of ACI 318-19 6.6.3.1.1 bracket the damaged states instead: $0.70 I_g$ for uncracked walls gives 0.648 s, which matches the 0.65 s identified after the first earthquake test EQ1 within 0.4 %, and $0.35 I_g$ for cracked walls gives 0.916 s, between the 0.82 s and 0.88 s identified after EQ2 and EQ3 and well short of the 1.16 s after the near-fault Sylmar record EQ4, which yielded the base of the wall [@panagiotou2010]. The close match after EQ1 is a single observation and should not be read as a calibration of the code factor. The comparison therefore places the program's own error, below 1 % in Sections 5.1 to 5.4, well inside the 3–8 % that modelling decisions add for a real building and the 30–80 % range that cracking adds, which is the order of priorities a user of Pondus should keep in mind.

## A continuous highway bridge under HL-93 loading

The moving-load analysis was calibrated against the published design of a two-span continuous composite steel I-girder bridge, Design Example 2A of the FHWA Steel Bridge Design Handbook [@fhwa2015de2a], whose two 90 ft spans carry four plate girders designed to AASHTO LRFD [@aashto2014]. Its Table 6 prints the unfactored live load moments per lane at the tenth points of span 1 under the HL-93 loading. These are the envelopes of the design truck, with its rear axle spacing free between 14 and 30 ft, and of the design tandem, the same envelopes with 33 % dynamic allowance plus the 0.64 klf lane load, and the special negative-moment loading of 90 % of two trucks at least 50 ft apart plus 90 % of the lane. The example analyses the girder with short-term composite moments of inertia of 48,806 in.⁴ in the positive bending region and 50,027 in.⁴ within 27 ft of the pier, and Pondus used the same girder, divided at the tenth points. The vehicle envelopes come from Pondus's moving-load analysis at a step of 0.5 ft over nineteen trains, the truck at nine rear spacings in both directions and the tandem. The lane load was placed on the parts of Pondus's influence line with the sign sought, because AASHTO allows it to be discontinuous.

All 40 comparisons agree within their tolerance, with a median error of 0.045 % and a largest of 0.65 % (Figure 3). The vehicle envelopes agree within 0.16 % at every tenth point, and the special loading gives −2020.1 kip-ft at the pier against the printed −2020 kip-ft. At 0.9L the influence line changes sign inside span 1, and its positive part carries 31.5 kip-ft of lane load both in Pondus and in an independent integration, whereas the table implies 29.6 kip-ft, which points to a coarser placement of the lane in the example, so that row was allowed 1 %. Two parts of the table were not compared. The special loading is defined only between the points of dead-load contraflexure, and the values printed away from the pier match no placement of two trucks. At 0.8L the printed −967 kip-ft would need a two-truck effect of −611 kip-ft, whereas neither Pondus nor an independent search over every placement finds more than −479.5 kip-ft, so the value appears to be an error in the table.

The first run exposed defect 14. Pondus read the envelope at a station from the engine's extreme over each element touching it, but the engine takes that extreme over both ends of an element, so a station carried the value one step away. Where the envelope changes quickly the result was too high, 958.7 instead of 951 kip-ft at 0.6L (+0.81 %), and an independent influence-line solution confirmed the table. The engine now also keeps the envelope at each end of an element, and Pondus reads the value at the station itself, interpolates inside an element and gives an extreme that falls between two stations to the nearer one. The absolute maximum moment of a simple span under a moving pair of axles is therefore still found exactly (Section 5.7).

## Stability, plastic collapse and the other advanced analyses

Euler columns with pinned, cantilever, fixed-pinned and fixed-fixed ends give their critical loads within 0.05 % of @timoshenko1961, including the printed coefficient 20.19 for the fixed-pinned case. A fixed-base portal with equal beam and column stiffness buckles in sway within 0.001 % of the root of $x\cot x = -6/G$, the alignment-chart equation, when its members are axially rigid, and 0.36 % lower when their real axial stiffness is kept. The P-Delta amplification of a cantilever at 0.4 $P_{cr}$ matches $3(\tan u - u)/u^3$ within 0.0001 %. Five plastic collapse cases of @neal and @horne, from a simple beam to a fixed-base portal whose combined mechanism governs, are reproduced exactly by the pushover analysis, and the two-span case shows that the hinge forms at $0.414L$ inside the span rather than at an element end. A moving pair of axles gives the absolute maximum moment $P(L - s/2)^2/2L = 405$ kN·m exactly, influence lines peak where @hibbeler says they should, a cantilever propped after its dead load carries the staged moments within 0.003 %, a cable stay elongates within 0.014 % of Ernst's equivalent modulus [@ernst1965], and a beam on a Winkler foundation deflects within 0.015 % and bends within 0.09 % of @hetenyi. The tension-only brace and the lift-off support reproduce their statics exactly.

## Section properties

The torsion constants of rectangles with $b/t$ from 1 to 10 from Pondus's section finite elements lie within 0.39 % of the coefficients that @timoshenko1970 print to three figures, and the frame formula Pondus uses for rectangular members lies within 0.19 %. The warping constant of an I section and the shear centre of a thin channel are within 0.07 % of their closed forms, and the area and second moment of five rolled H shapes computed from their plates and fillets agree with JIS G 3192 [@jis3192] within 0.02 % and 0.25 %.

# Concrete, timber and masonry design

## Slab coefficients

The two-way slab design of Pondus follows Method 2 of ACI 318-63 [@aci31863], the method that the Thai standard EIT 1008 adopts, and the coefficient table had been written from a secondary reproduction with only its interior-panel row confirmed. The calibration found a scan of the original Table I in lecture notes of the University of Basrah [@hussain], and every one of its 91 coefficients, for the five edge conditions, six span ratios and the long span, equals Pondus's table exactly. A further 13 rows confirm that span ratios below 0.5 take the column for 0.5 and less. Both worked examples of the notes are reproduced through Pondus's slab design within 0.06 %. The notes themselves swap two row labels and transpose one coefficient in an example, which the comparison exposed and which the calibration records. The one-way coefficients of ACI 318-19 Table 6.5.2 agree within 0.16 % with a StructurePoint reproduction of @wight Example 5-7, except where Pondus is deliberately or newly conservative, as described in Section 8.

## Beams

Flexure, shear, torsion and deflection were compared clause by clause. The INTI singly reinforced beam gives $\phi M_n$ within 0.01 %, and the required tension steel of a simply supported beam by @wight agrees within 0.02 %. The torsion terms of Wight Example 7-2, a 14 × 24 in cantilever under 28 kip-ft, agree within 0.05 % for $A_{oh}$, $p_h$, $A_o$, $\phi T_{th}$, $\phi T_{cr}$, $A_t/s$, $A_l$, the spacing limit and the cross-section limit of 22.7.7.1. The quantities that contain the rounded SI constants, $\phi V_c$, $V_s$, $A_{l,min}$ and the minimum transverse steel, differ by the offsets those constants imply and by no more. For deflection, the cracked section and cracked inertia agree within 0.05 %, while the effective inertia is the expression of ACI 318-19 Table 24.2.3.5, which the 318-14 example replaces with Branson's equation, so the effective inertia was evaluated independently and agrees exactly, and the 7.6 % gap to the example's Branson value is the intended change between editions.

## Columns and footings

The interaction diagram of a 16 × 16 in tied column with twelve #9 bars reproduces $P_0$ and $\phi P_{n,max}$ exactly and the axial forces and moments at the four printed neutral-axis depths within 0.74 %, the residue of $\beta_1 = 0.804$ in the SI expression against 0.80 in the psi expression. The search that Pondus's column design uses returns $\phi M_n$ at each printed $\phi P_n$ within 0.37 %. For biaxial bending Pondus uses Bresler's load contour [@bresler1960] with $\alpha = 1.15$ on its own uniaxial capacities, and on the example of Pincheira and co-authors reproduced by StructurePoint it gives a capacity 8.2–8.4 % below the exact skewed-axis point, which quantifies the conservatism of the method rather than an error of the code. The non-sway moment magnifier, the critical load by option (a) of 6.6.4.4.4 and the minimum moment agree within 0.85 %. The isolated footing of @wight Example 15-2 gives the moment at the column face and the reinforcement within 0.03 %.

## Plate reinforcement, timber and masonry

The Wood–Armer moments [@wood1968; @armer1968] were evaluated on seven moment fields that cover every branch of the normal and special rules, and all 28 design moments agree exactly. The NDS column stability factor of a timber column [@nds2018] agrees with the Dlubal example within 0.08 %, after the calibration noticed that the example's printed adjusted compressive strength does not follow from its own stability factor. No accessible published masonry example was obtained, so the TMS 402 flexural check [@tms402] was compared with its closed form only.

# Defects found by the calibration

Table 6 lists fourteen defects with their effect on a design before the fix. Twelve were found by the calibration, and two, the staged member forces and the sign of the Winkler coupling, by the closed-form tests that preceded it during development, which are included because they change design forces in the same way. Six were unconservative, four were conservative, three returned wrong results without a clear direction, and one, the engine's single coefficient of thermal expansion, overestimated restraint forces in concrete members by 20 %. Every defect was fixed and every fix was followed by a run of the whole test suite. The development tests also corrected two reporting errors that do not enter a design, a pushover capacity curve that plotted the displacement increment of each event as if it were the total and an influence line sampled beside its section, whose peak was 3.6 % low.

The location of the defects is the main lesson. Only one of the fourteen, the sign in the Winkler foundation matrix, was an error of a numerical kernel. The frame stiffness matrices, the solvers, the eigenvalue analysis, the plastic event-to-event algorithm and the code formulas of the engine's checkers were correct wherever they were reached. Nine defects sat in Pondus's own code that decides what the kernel is asked: which axis a modulus belongs to, which branch of a spectrum a period falls on, which length the minor axis buckles over, which web limit a beam-column is classed by, which coefficient a destabilising load takes, which strength a stirrup has, which area a bolted member ruptures across, which moment coefficient a two-span slab needs and how stiff a modelling device such as a rigid arm may be made before the solver loses precision. Defect 13 is instructive because the kernel was right and the inputs were legal: the error came from a modelling convenience, an arbitrarily large stiffness, that is harmless in small models and was invisible to the existing wall tests, which had 20 storeys or fewer. Four of the defects, the two in the moving-load envelope, the staged member forces and the thermal coefficient, are limitations of the vendored engine that its own suite did not expose because they only matter for the inputs a design program sends. That pattern agrees with the general experience of verification that interfaces and defaults, not algorithms, carry most of the risk [@oberkampf2010], and it matters more when an agent is the user, because an agent has no habit of distrusting a number that looks plausible.

A second lesson concerns the tests that existed before the calibration. Pondus already had tests against closed-form results, and they passed. They did not catch defect 3 because they gave the Winkler modulus as $[k, k]$, they did not catch defect 1 because no test structure was stiff enough to fall below $T_0$, and they did not catch defect 8 because no test had a bolted tension member. Published examples do better than self-written tests because their authors chose cases for engineering reasons rather than to exercise the code, and because the printed intermediate values pin each clause separately.

# Limitations of the calibration

The calibration has limits that a user of Pondus should know. The ELF vertical force distribution is not calibrated because Pondus does not compute it: it scales the response spectrum result to the ELF base shear instead. Only a single-degree-of-freedom time history was calibrated. The cables are small-displacement trusses with Ernst's modulus, so slack cables under large transverse loads are outside what Pondus solves. The plate results are Mindlin results, which exceed the Kirchhoff tables for thick slabs by a physical shear deformation and, at the default mesh, run 3–5 % low in deflection. In steel design, the AISC shear tab and the AISI cold-formed checks were not compared with printed examples because none was obtained in text form, and block shear, the tension increase of $C_b$ in H1.2, the thickness reduction of the yield strength in EN 10025 and the lateral-torsional buckling method of 6.3.2.3 are not implemented. In concrete design, Pondus has no capacity function for a given doubly reinforced section, assumes a sustained load ratio of 0.6 in the slender column stiffness, and does not design punching shear or slab deflection, and the masonry interaction check is the engine's linear sum.

The shear-wall calibration has limits of its own. The walls are wide columns, so they carry no in-plane flexibility between the pier and the wall's ends, which is right for walls whose length is small against the storey span but not for long walls with openings or for coupled walls, whose coupling beams were not calibrated. The references are linear and elastic: cracked-section stiffness, the nonlinear response of walls and the ACI 318 design of boundary elements were not compared with published examples. The wall-frame comparisons rest on a continuum solved in the test rather than on printed numbers, which was mitigated by checking the solver against its two limits and against an independent finite-element solution. The validation rests on a single building, on its linear dynamic properties only and on a seismic weight inferred from the design base shear, and Pondus's linear time history was not compared with the measured earthquake response, which was nonlinear from the second test on. Weightless members receive a minimum density of 1 kg/m³, which in these lightly loaded benchmark models adds about 0.2 % to the mass and is negligible in a building.

The sources also have limits. Some published values reach the calibration through reproductions, such as Stabileo's records of the AISC and Eurocode examples, StructurePoint's versions of textbook examples and a lecture-note scan of the 1963 coefficient table, so a transcription error in a reproduction would pass into the reference. Where a reproduction contradicted itself, as in a misprinted timber strength, a swapped label in the slab notes and an inconsistent load table in a slenderness example, the calibration followed the calculation that the source actually performs and recorded the inconsistency. Most clauses are checked by one or two examples, which is enough to expose a wrong formula but not to prove that every branch of a long clause is right. The tolerance of 0.5 % was chosen to match the precision of printed examples, and it cannot detect an error smaller than that.

# Conclusions

Pondus reproduces 430 of 470 published, closed-form and independent reference values within 0.5 % and 449 within 1 %, across analysis, shear walls under earthquake and dynamic loading, a continuous bridge under moving load, steel, concrete, timber and masonry, and the remaining 21 differences are explained by mesh convergence, a conservative method for biaxial bending, the rounded SI constants of ACI 318 and the shear deformation of walls that the Euler–Bernoulli references omit. Walls coupled to frames reproduce the flexural–shear continuum within 0.33 % in the first frequency over $\alpha H$ from 0.5 to 8, and a wall on one side of a plan reproduces the coupled torsional modes and the CQC base shear within 0.05 %. The HL-93 envelopes of a published two-span bridge design are reproduced within 0.16 % for the vehicles and within 0.65 % with the lane load. Against the full-scale UCSD–NEES wall building, a bare-wall Pondus model with gross sections lies 6.2 % long in the first period and 0.9 % off in the second-mode frequency, which is the size of the effect of the elements a lateral-system model leaves out, whereas the choice between gross and cracked stiffness changes the first period by 20 % to 70 %. The ACI 318-63 Method 2 coefficient table, previously confirmed for one row, now agrees with the published table in all 91 coefficients. The calibration and the closed-form tests before it found and fixed fourteen defects, six of them unconservative and three of them capable of changing a design by 40 % or more, and thirteen of the fourteen lay in the code between the model and the numerical kernels rather than in the kernels themselves.

For software that agents will drive, these results suggest a practical rule. Verification effort should follow the data across every interface, from the model to the inputs of each check, and should use published examples whose intermediate values pin each clause, because that is where errors are made and where neither the agent nor a self-written test is likely to notice them. The calibration suite is part of the program's test suite, so every future change to Pondus is checked against the same 470 references.
